# User Story: Select book

As a **Bible researcher**\
I want to be able to **pick** the Bible **book** from the current version\
In order to quckly navigate to the desired one

## Requirements

### R1: user can see the list of the Bible version books to select from

E: should display the full list of the current Bible version books when user wants to change the current one

### R2: user can change the current Bible book

E: should change the current Bible book using the full list of books

### R3: when user changes the current Bible book he keeps reading the same passage of the same Bible version

E: should keep reading the same Bible version when changing the Bible book 

E: should keep reading the same chapter when changing Bible book 

E: should keep reading the same verse when changing Bible book 

### R4: user can see the current Bible book while reading a chapter

E: should display the current Bible book when reading the Bible
