# User Story: Select chapter

As a **Bible researcher**\
I want to be able to **pick** the Bible **chapter** from the current book\
In order to quckly navigate to the desired one

## Acceptance Criteria

### R1: user can see the list of the Bible book chapters to select from

E: should display the full list of the current Bible book chapters when user wants to change the current one

### R2: user can change the current Bible chapter

E: should change the current Bible chapter using the full list of chapters

### R3: when user changes the current Bible chapter he keeps reading the same passage of the same Bible version

E: should keep reading the same Bible version when changing the Bible chapter 

E: should keep reading the same book when changing Bible chapter 

E: should keep reading the same verse when changing Bible chapter 

### R4: user can see the current Bible chapter number while reading a chapter

E: should display the current Bible chapter number when reading the Bible
