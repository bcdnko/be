# User Story: Select version

As a **Bible researcher**\
I want to be able to **pick** the Bible **version** to read\
In order to compare different translations and corpuses

## Acceptance Criteria

### R1: user can see the list of the Bible versions to select from

E: should display the full list of Bible versions when user wants to change the current version

### R2: user can change the current Bible version

E: should change the current Bible version using the full list of versions

### R3: when user changes the current Bible version he keeps reading the same passage

E: should keep reading the same book when changing Bible version 

E: should keep reading the same chapter when changing Bible version 

E: should keep reading the same verse when changing Bible version 

### R4: user can see the current Bible version while reading a chapter

E: should display the current Bible version when reading the Bible
