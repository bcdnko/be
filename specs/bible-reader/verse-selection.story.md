# User Story: Select verse

As a **Bible researcher**\
I want to **select** the Bible **verse**\
In order to perform different operations with it

## Acceptance Criteria

### R1: user can select one or more verses

E: should select one verse

E: should select multiple verses

### R2: user can unselect one or more verses

E: should unselect one verse

E: should unselect multiple verses

### R3: selection is reset when user changes chapter

E: should reset selection when user goes to the next chapter

E: should reset selection when user goes to the previous chapter

E: should reset selection when user goes to a random chapter

E: should reset selection when user goes to another book

### R4: selection is preserved when user changes Bible version

E: should preserve selection when user changes the Bible version
